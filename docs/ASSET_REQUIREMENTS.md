# オリジナルアイコン・アセット 必要一覧

最終更新: 2026-07-25

このアプリのビジュアル素材をオリジナルで作るために必要なものを、
用途・サイズ・優先度つきでまとめたものです。

---

## 0. 現状

もともと `app.json` が参照していた 4 ファイルはすべて **1×1 ピクセルのプレースホルダ**
（70 バイト）で、実体のある画像は Expo テンプレートの既定画像（猫とは無関係）でした。
つまり **ゼロから作る前提**です。

### ✅ 暫定版を実装済み

`scripts/generate_icons.py`（Pillow）でパレット準拠のフラットな猫アイコンを生成し、
下記を差し替え済みです。**AI 生成ではなくプログラム描画による暫定版**なので、
より作り込んだものができ次第そのまま置き換えてください。

```bash
pip install Pillow
python3 scripts/generate_icons.py     # 形や色はこのファイルの数値で調整
```

## 2. 【最優先】OS・ストア用アイコン

これが無いとストア申請ができません。**まずここから。**

| # | ファイル | サイズ | 形式 | 要件 |
|---|---|---|---|---|
| A-1 | `assets/icon.png` | **1024×1024** | PNG | iOS / 共通アプリアイコン。**透過なし**、角丸なし（OS 側で処理）。フルブリードで塗る |
| A-2 | `assets/adaptive-icon.png` | **1024×1024** | PNG（透過） | Android アダプティブアイコンの**前景**。中央 66%（直径 約672px）の安全領域内に主要素を収める。外周は切られる前提 |
| A-3 | `assets/splash.png` | **1284×2778** 推奨<br>（または中央ロゴ 1200×1200） | PNG（透過） | 起動画面。`resizeMode: contain` なので余白込みで作る |
| A-4 | `assets/favicon.png` | **196×196**（48×48 も可） | PNG | Web 版のタブアイコン |
| A-5 | 通知アイコン（Android） | **96×96** | PNG（透過） | **白のシルエットのみ**。色は `app.json` の `color` で着色される。※現在未設定なので `app.json` への追加も必要 |

### 補足
- Android アダプティブアイコンの**背景**は現在べた塗り色指定です。
  背景も画像にしたい場合は 1024×1024 をもう 1 枚。
- Android 13+ のテーマアイコン（monochrome）に対応するなら、
  単色シルエット 1024×1024 を追加。

## 5. オリジナル化してはいけないもの

| 項目 | 理由 |
|---|---|
| **Google サインインのロゴ** | Google のブランドガイドライン上、公式アセットの使用が必須。独自デザイン不可。現在は文字「G」で代用しているため、**公式ロゴへの差し替えが必要** |

## 6. 納品形式の推奨

### マスターデータ
**SVG**（または元データ）でいただけると、色替え・サイズ変更に強く、
ダーク/ライト両テーマへの追従も容易です。

### 実装方法の選択肢

| 方式 | メリット | 必要な作業 |
|---|---|---|
| **A. SVG コンポーネント**（推奨） | 解像度非依存・色をテーマから流し込める | `react-native-svg`（SDK 50 なら `~14.1.0`）の追加が必要 |
| B. PNG スプライト | 追加依存なし。今すぐ使える | `@1x/@2x/@3x` の 3 セットが必要。色替え不可 |
| C. アイコンフォント | 軽量・色変更容易 | フォント生成の工程が増える |

**A を推奨**します。ライト/ダークで色を変える箇所が多く、
PNG だと同じ絵を 2 色分持つことになるためです。

### ファイル名の規約案
```
assets/icons/tab-home.svg
assets/icons/cat-color-tabby.svg
assets/icons/mood-happy.svg
assets/icons/category-meal.svg
assets/icons/health-weight.svg
assets/icons/ui-search.svg
assets/illustrations/empty-cats.svg
```

## 8. デザイン上の制約チェックリスト

- [ ] 小サイズ（16〜24pt）で潰れないか — カテゴリタグは特に小さい
- [ ] ライト背景 `#FBF1E6` とダーク背景 `#1E1A16` の両方で視認できるか
- [ ] 猫の毛色 6 種が、白猫とグレーを含めて**背景に溶けないか**
- [ ] タブバーの選択 / 非選択が色だけでなく形でも区別できるか（アクセシビリティ）
- [ ] Android アダプティブアイコンの安全領域（中央 66%）を越えていないか
- [ ] 通知アイコンが白シルエット単色で成立するか
